# WorkshopHub

A decentralized workshop booking system built on Stacks blockchain. Connects skilled instructors with learners for hands-on educational workshops and skill-building training sessions.

## Features
- Instructor registration with subject specialization
- Workshop booking with automatic payment processing
- Administrator approval system for instructor quality control
- Comprehensive booking tracking and attendance management

## Usage
Deploy with Clarinet for decentralized workshop booking and educational session management.
